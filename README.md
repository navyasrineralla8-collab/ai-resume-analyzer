# ai-resume-analyzer
AI-powered Resume Analyzer using Python, Streamlit, PyPDF2, and Scikit-learn.
# AI Resume Analyzer

## Features
- Upload PDF resume
- Extract text from PDF
- Find skills
- Compare resume with job description
- Calculate similarity score

## Technologies
- Python
- Streamlit
- PyPDF2
- Scikit-learn

## Run

pip install -r requirements.txt

streamlit run app.py
